# Python 与 C++ 对象采集和源码归一化

适用当前 trace-api-chain 集成版本。pytest 只写原始证据；以下“归一化”均在独立重放阶段完成，HTML 另行从数据库读取。

## 先区分三件事

“采集对象”表示记录身份、类型与已观测引用，不等于序列化完整对象值；“展开成员”表示继续遍历该对象可读的引用；“归并源码”表示离线阶段证明它属于哪一个源码定义。一个对象可以已采集但不展开，也可以已采集但因缺少源码锚点而进入 pending。

## C++ 对象与事件分类对照

当前 C++ 后端采集的是函数事件，不是 C++ 对象堆。Python 层观察到 Tensor 包装对象，不代表观察到了 TensorImpl 或 Storage 内部对象。

| 对象或场景 | 当前结果 | 原因与代码证据 |
| --- | --- | --- |
| 已插桩的主机函数，当前线程窗口开启且实际执行 | 记录进入/退出、function/caller 地址、时间、PID/TID 和连续序号 | [hooks.c](../src/hooks.c#L14) 的 `struct event`、`record` 与两个 `__cyg_profile_func_*` |
| C++ 实例、this、成员、参数值、返回对象、局部变量 | 不直接采集对象内容或引用关系 | `struct event` 没有这些字段，hook 仅接收 fn/caller；[hooks.c](../src/hooks.c#L14) |
| C++ 构造函数、析构函数、私有方法 | 满足插桩和窗口条件时可有函数事件；不能据此恢复完整对象生命周期 | `record` 不按方法名过滤，但没有对象地址字段；[hooks.c](../src/hooks.c#L48) |
| 未插桩函数、窗口外执行、其他未启用线程 | 没有该后端的函数记录 | 未插桩不会调用 hook；TLS enabled 未开启时直接 return；[hooks.c](../src/hooks.c#L15)、[hooks.c](../src/hooks.c#L48) |
| CUDA/NPU device 内部执行与对象 | 当前后端不采集；主机侧调度函数仍按主机规则记录 | hook 使用主机线程 TLS、getpid/gettid，未接入设备侧事件或内存读取；[hooks.c](../src/hooks.c#L15) |
| 缓冲区溢出、写出失败 | 已记录部分保留，失败状态上报；不能称为完整采集 | `record` 设置 failed，`trace_index_stop` 返回 -1；[hooks.c](../src/hooks.c#L48)、[native.py](../src/native.py#L49) |
| 有函数地址但缺少唯一源码定义 | 函数事件仍被采集；离线保留 unresolved 二进制身份，不强行归并源码 | [SourceEntities.cpp](../src/source_entities.py#L81) 的明确回退分支 |

## Python 采集范围

被采集调用的 Python 入口、行事件和返回时做快照；实际 LOAD_GLOBAL/LOAD_NAME、C callable 和 receiver 也是入口。精确 list/tuple/dict/set/frozenset 遍历全部引用，受单次预算限制。普通实例读取内建字典/slot 存储描述符；函数展开默认值和闭包；绑定方法展开 receiver 和函数。别名引用保留，循环只展开一次。

标量也可以有身份/类型记录，但不保存具体数值。class/module/code 对象不自动展开整个命名空间。测试文件默认局部快照被排除；C 参数和 C 返回值不由 profile 事件直接枚举；property 不主动求值；自定义容器不保证枚举成员；Tensor 底层 C++ 存储不读取。没有进入任何快照或可达引用的瞬时对象可能遗漏，不能推断它无关。

线程边界、预算溢出和 profiling hook 被替换分别作为范围边界或缺口处理，不是对象重要性过滤。根入口按 catalog.py 的运行时身份映射，不按名字相似匹配。torch.compile 及约定的编译子系统子树有显式排除记录。

## 修改后端类的例子

假设 Backend 新增 `self.__worker = Worker()` 和 `__consume()`，其他调用方不改。

- 若 Backend.run 在采集范围内，入口 locals 中的 self 可使既有 Backend 实例被发现，不要求捕获构造过程。
- 实例字典或 slots 中已存在的私有成员按普通引用遍历。双下划线改写后的存储键没有被过滤，因此能找到 Worker。
- __consume 实际执行并经过采集事件时才形成调用节点。看到对象或类定义不等于方法执行过。
- 若顺序是测试→Backend.run→torch.add，而采集直到 torch.add 才开始，不能向外补采 Backend 的 self。将后端模块加入 --callchain-namespaces 可让它的公开入口进入目录。
- 修改后要重新采集，旧证据不能补出新字段。若修改的是 C++ 类，当前只有函数调用事件，没有私有成员实例图。

## Python 源码合并

函数 code object 的源码位置与 AST 定义唯一匹配时，使用源码文件、kind、源码 qualname 和同名定义序号形成实体键。运行时名字只作为 aliases。多个调用、导出别名和实例可以指向同一个源码实体。

类使用已观测实例自身方法的代码位置寻找唯一类归属。这是可核验的源码归属证据，并非动态类创建事件；无法唯一确定时不合并。类体变化更新内容版本，依赖旧版本的其他采集贡献失效。修改关联是候选关系，不等于改动行执行过或行为一定变化。

## C++ 采集与源码合并

hooks.c 只记录函数地址、caller、时间、pid/tid、进入退出和连续序号。没有 this、参数值、返回对象、局部变量、成员或 GPU 数据字段。函数被记录的条件是已插桩、实际触发钩子、当前线程窗口开启且容量未耗尽。

窗口外、未配置线程、未插桩函数和 CUDA device 内部活动不在此后端范围内。容量耗尽返回失败，不是正常过滤。Python Tensor receiver 可见不代表 native TensorImpl 已被读取。

离线先用 ELF 地址证明函数身份，再读取 DWARF 声明位置。运行时符号可作为别名，不能用它猜源码实体。相同声明 identity 可以归并；重载/linkage 不同的定义保留分离。缺少唯一声明时保留未解析二进制身份，不用附近的执行行冒充定义。

## SQL 与 API 路径

entities 保存源码实体；aliases 保存名字；paths 保存 API 和祖先上下文；path_support 与 capture_slots 保存有界的最新证据贡献；pending 保存未确定归属。原始事件留在采集目录，不把整个调用历史不断复制进主库。

一个共享类/函数可以被多个 API 使用。合并源码实体后，API A 的分支不能因为 API B 也调用了它而被接入 A。生成页面时查询带上下文的 paths，不对全局合并关系任意做可达闭包。

def instance_fields(value, plans=None):
    """Only builtin storage descriptors; never invoke a property or repr."""
    result=[]; notes=[]
    cls=type(value)
    try:
        plan=plans.get(cls) if plans is not None else None
        if plan is None:
            mro=type.__dict__['__mro__'].__get__(cls, type(cls))
            seen=set();plan=[]
            for base in mro:
                for name,descriptor in class_namespace(base).items():
                    if name in seen:continue
                    seen.add(name)
                    if (name=='__dict__' and type(descriptor) is types.GetSetDescriptorType) or type(descriptor) in (types.MemberDescriptorType,property):
                        plan.append((name,descriptor))
            if plans is not None:plans[cls]=plan
        for name, descriptor in plan:
                if name == '__dict__' and type(descriptor) is types.GetSetDescriptorType:
                    try:
                        fields=descriptor.__get__(value,cls)
                        if type(fields) is dict:
                            result.extend(('attribute:'+str(k),v) for k,v in fields.copy().items() if type(k) is str)
                    except Exception as exc: notes.append(type(exc).__name__+':__dict__')
                elif type(descriptor) is types.MemberDescriptorType:
                    try: result.append(('slot:'+name,descriptor.__get__(value,cls)))
                    except AttributeError: pass
                    except Exception as exc: notes.append(type(exc).__name__+':'+name)
                elif type(descriptor) is property:
                    notes.append('property_not_evaluated:'+name)
    except Exception as exc: notes.append('storage_unavailable:'+type(exc).__name__)
    return result,notes
```

    def metadata(self, value, labels=None):
        cls=type(value)
        if labels is None:label=class_label(cls)
        else:
            if cls not in labels:labels[cls]=class_label(cls)
            label=labels[cls]
        token='object:'+str(id(value))+':'+str(id(cls))
        result={'id':token,'address':id(value),'type':label,'identity':'observation_address'}
        if type(value) is types.FunctionType:
            result.update(kind='function',definition=self.code(value.__code__,value.__module__))
        elif type(value) is types.MethodType:
            result.update(kind='bound_method',definition=self.code(value.__func__.__code__,value.__func__.__module__))
        elif issubclass(type(value),type):
            result.update(kind='class',static_owner=class_label(value))
        elif type(value) is types.ModuleType:
            result.update(kind='module',static_owner={'module':vars(value).get('__name__'),'qualname':None})
        elif type(value) in (types.BuiltinFunctionType,types.BuiltinMethodType):
            result.update(kind='native_callable',name=value.__name__,module=value.__module__)
        else:
            result.update(kind='instance',static_owner=label)
        owner=result.get('static_owner') or {}
        module=sys.modules.get(owner.get('module'))
        if type(module) is types.ModuleType:
            result['owner_file']=vars(module).get('__file__')
        # Exported classes can have __module__ rewritten (e.g. torch.Tensor).
        # Their own Python methods retain the actual defining source path.
        owner_class=value if result['kind']=='class' else cls if result['kind']=='instance' else None
        class_key=(id(owner_class),owner.get('module'),owner.get('qualname')) if owner_class is not None else None
        if class_key in self.class_sources:
            result.update(self.class_sources[class_key])
        elif owner_class is not None and owner.get('module')!='builtins':
            candidates=set()
            hints=[]
            for member in class_namespace(owner_class).values():
                if type(member) in (staticmethod,classmethod):member=member.__func__
                if type(member) is types.FunctionType:
                    candidates.add(member.__code__.co_filename)
                    try:
                        stat=os.stat(member.__code__.co_filename)
                        stamp=[stat.st_size,stat.st_mtime_ns]
                    except OSError:stamp=None
                    hints.append({'file':member.__code__.co_filename,'first_line':member.__code__.co_firstlineno,
                                  'source_stamp':stamp,'evidence':'class_own_method_code_location'})
            if hints:result['class_source_hints']=hints
            if len(candidates)==1:result['owner_file']=next(iter(candidates))
            elif len(candidates)>1:result['owner_candidates']=sorted(candidates)
            self.class_sources[class_key]={k:result[k] for k in ('owner_file','owner_candidates','class_source_hints') if k in result}
        # CPython reuses short-lived builtin-method addresses. Never overwrite
        # a previous fill_ object with append merely because the address matches.
        semantic={k:v for k,v in result.items() if k not in ('id','address','identity')}
        previous=self.object_semantics.get(token)
        if previous and previous[0]==semantic:
            result['id']=previous[1]
        else:
            result['id']=token+':'+hashlib.sha256(json.dumps(semantic,sort_keys=True).encode()).hexdigest()[:16]
            self.object_semantics[token]=(semantic,result['id'])
        token=result['id']
        return token,result
```

    def trace(self, frame, event, arg):
        if self.suppressed or threading.get_ident()!=self.thread:return None
        if self.body_code is not None and not self.body_depth and not self.stack:return None
        if event=='call' and not self.stack and not self.framework(frame.f_globals.get('__name__')):return None
        if event=='call' and (self.stack or self.framework(frame.f_globals.get('__name__'))):
            key=id(frame.f_code)
            if key not in self.global_loads:
                self.global_loads[key]={i.offset:(i.opname,i.argval) for i in dis.get_instructions(frame.f_code) if i.opname in ('LOAD_GLOBAL','LOAD_NAME')}
            frame.f_trace_opcodes=bool(self.global_loads[key])
        if event=='opcode' and self.stack and not self.busy and self.stack[-1]['kind']=='python' and self.stack[-1]['frame']==id(frame):
            instruction=self.global_loads.get(id(frame.f_code),{}).get(frame.f_lasti)
            if instruction:
                opname,name=instruction
                scopes=([frame.f_locals] if opname=='LOAD_NAME' else [])+[frame.f_globals,frame.f_builtins]
                for scope in scopes:
                    if name in scope:
                        self.busy=True
                        try:self.snapshot(frame,'global_read',{'global:'+name:scope[name]})
                        except Exception as exc:self.gaps.add('global_observation_error:'+type(exc).__name__)
                        finally:self.busy=False
                        break
        if event=='line' and self.stack and not self.busy and self.stack[-1]['kind']=='python' and self.stack[-1]['frame']==id(frame):

/* This validation backend explicitly scopes each recording to the calling
 * thread. No dladdr, symbol lookup, locks or write syscalls in the hot path.
 * A fixed budget and short writes are reported, never silently discarded. */
struct event { uint64_t time_ns, function, caller; uint32_t pid, tid, kind, reserved; };
static __thread struct event *events;
static __thread size_t used, capacity;
static __thread uint32_t sequence;
static __thread int enabled, fd = -1, failed;
static __thread uint32_t process_id, thread_id;

int trace_index_interposed(void) {
    Dl_info self = {0}, active = {0};
    dladdr((void *)trace_index_interposed, &self);
    dladdr(dlsym(RTLD_DEFAULT, "__cyg_profile_func_enter"), &active);
    return self.dli_fbase && self.dli_fbase == active.dli_fbase;
}

void trace_index_context(const char *test, const char *phase) { (void)test; (void)phase; }

    (void)fn; (void)b; (void)p; (void)h; (void)l;
}

int trace_index_configure(const char *path) {
    if (fd >= 0) return -1;
    const char *limit = getenv("TRACE_API_CHAIN_MAX_EVENTS");
    capacity = limit ? strtoull(limit, NULL, 10) : 262144;
    if (!capacity || capacity > 10000000) return -1;
    if (!events) events = malloc(capacity * sizeof(*events));
    if (!events) return -1;
    fd = open(path, O_WRONLY | O_CREAT | O_EXCL, 0600);
    if (fd < 0) return -1;
    used = 0; failed = 0;
    process_id = (uint32_t)getpid(); thread_id = (uint32_t)syscall(SYS_gettid);
    enabled = 1;
    return 0;
}

static void record(void *function, void *caller, uint32_t kind) {
    if (!enabled) return;
    if (used >= capacity) { failed = 1; return; }
    struct timespec now;
    clock_gettime(CLOCK_MONOTONIC, &now);
    events[used++] = (struct event){
        (uint64_t)now.tv_sec * 1000000000ULL + now.tv_nsec,
        (uintptr_t)function, (uintptr_t)caller, process_id, thread_id, kind, sequence++};
}
void __cyg_profile_func_enter(void *fn, void *caller) { record(fn, caller, 1); }
void __cyg_profile_func_exit(void *fn, void *caller) { record(fn, caller, 2); }

static int write_all(const char *data, size_t count) {
    while (count) {
        ssize_t n = write(fd, data, count);
        if (n < 0 && errno == EINTR) continue;
        if (n <= 0) return -1;
        data += n; count -= (size_t)n;
    }
    return 0;
}
