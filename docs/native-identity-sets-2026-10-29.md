## 改动

完整引用图签名在每次观察中用 Python set 保存临时整数地址，用于判断某节点、
某类型及某基类命名空间是否已经处理。这里只需要地址相等判断，无需制造 Python
整数对象，也不依赖集合迭代顺序。

替换为每次签名私有的 C 开放寻址集合：精确比较完整地址，碰撞线性探测，按容量
扩容，结束后释放。不持有或解引用工作负载对象；原队列的引用持有与释放方式不变。
完整遍历、BFS 顺序、每条边的预算计数、类型/代码/命名空间校验、序列化字节
均保持。重复边也照常计入预算。将小段字节编码内联以减少函数调用成本。
